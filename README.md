# Kalkidan Shewit — Portfolio

My personal developer portfolio, built to showcase my projects, skills, and experience.

## About

Hi, I'm Kalkidan Shewit, a Fullstack Developer based in Addis Ababa, Ethiopia.

I enjoy building interfaces that are visually interesting while keeping the backend reliable and practical.

This portfolio is designed around a bookshelf/archive concept where each project is presented as a rolled paper that can be opened to read more about the project.

## Built With

- React
- JavaScript
- CSS
- Vite

## Features

- Personal introduction
- Social links
- Interactive project bookshelf
- Individual project pages/readme-style views
- Live project links
- GitHub links
- Responsive design

## Projects

Projects currently showcased include:

- Kmedia — Full-stack social media platform
- Blog — Full-stack blogging platform
- Telegram Community — Community-focused platform

More projects will be added over time.

## Why I Built This

I wanted my portfolio to feel different from a typical developer portfolio while still being simple, clean, and easy to navigate.

The bookshelf concept represents my projects as things I've built and collected over time, with each project having its own "page" to explore.
